# Design-to-Code: AI-Driven Amazon A+ Page Engine

这是一个由 AI 驱动的 **“设计即代码”（Design-to-Code）** 实践项目，专门用于生成符合亚马逊 A+ 页面标准的电商产品详情页[cite: 2]。该项目实现了从视觉感性设计到工业级生产代码的精准映射。

## 核心价值：像素级可控性 (Precision Control)
作为设计师，本项目解决了传统开发中“还原度损耗”的痛点。通过 HTML 构建，实现了对页面底层逻辑的绝对控制：
*   **标准化页面布局**：严格遵循 1200px 页面宽度规范[cite: 1]。
*   **全模块结构支持**：涵盖从 Header、功能展示到 Footer 的完整电商页面链路[cite: 1]。
*   **视觉规范自动化**：内置了 72px 品牌标题、14px-42px 的多层级字号体系[cite: 1]。
*   **精确色彩管理**：严格执行 #111 (标题) 与 #666 (正文) 的色彩科学[cite: 1]。
*   **品牌基因嵌入**：系统级应用 #c5a863（金色）作为强调色，确保功能卖点与细节标注的高级感[cite: 1]。

## 项目特性与模块实现
项目深度集成了一套针对特定类目（如裤链/Zipper）的视觉逻辑系统[cite: 1]：
*   **Features 模块**：利用 CSS 实现 400px 圆形中心图与卖点块之间的金色渐变虚线连接[cite: 1]。
*   **Scenarios 模块**：通过 2x2 田字格布局展示应用场景，支持顶部 20px 圆角处理及中心圆叠加逻辑[cite: 1]。
*   **Details 模块**：16:10 比例的全屏背景图布局，右移 20% 适配以预留左侧 240px 的渐变标注区[cite: 1]。
*   **高保真导出**：内置 4 倍清晰度导出功能，支持跨域图片处理并可自动打包为 Zip 压缩包[cite: 1]。

## 技术架构
该项目不仅是 HTML 模板，更是一套 **AI Agent 协作流** 的成果展示：
1.  **视觉解析 Agent**：理解设计稿层级与视觉权重。
2.  **布局决策 Agent**：通过长链推理，在 Flex 与 Grid 布局间选择最优解。
3.  **代码审计 Agent**：确保生成的 HTML 符合语义化标准并具备高度可维护性。
